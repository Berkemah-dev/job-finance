# DUPLICATE FEATURES — JobFinance

Daftar pasangan fitur yang diduga dobel, hasil pengecekan dependency/route/consumer. Status keputusan = rekomendasi audit (menunggu persetujuan sebelum eksekusi).

| Feature A | Feature B | Problem | Decision |
| --------- | --------- | ------- | -------- |
| Route group `jobs.*` (Resource) — `routes/web.php:95-96` | Route group `job-orders.*` alias — `web.php:97-99` | Keduanya memanggil `JobController::index/show/edit` yang sama; halaman dan menu berbeda hanya memperlihatkan URL berbeda. Dua URL untuk fungsi identik. | **MERGE**: jadikan `jobs.*` kanonik; hapus alias `job-orders.*`; perbarui navigasi/menu supaya konsisten (hindari duplikasi rute). |
| `/documents` → `/dokumen-job` redirect — `web.php:70` | `/dokumen-job/...` group — `web.php:71-79` | Redirect + nama path dwibahasa; `documents.index/show` semua hidup di `/dokumen-job`. | **MERGE**: pertahankan satu path kanonik (`/dokumen-job`); hapus `Route::redirect('/documents',...)` dan pastikan seluruh `route('documents.*')` konsisten. |
| Tabel `job_shipment_statuses` (`2026_09_10_000010:18-30`) + model `JobShipmentStatus` | Tabel `job_status_history` (`2026_09_10_000007:35`) | `Job::shipmentStatusHistory()` (`Job.php:25-27`) dan `statusHistory()` (`:20-23`) sama-sama `hasMany(JobStatusHistory)` → status shipment ditulis ke `job_status_history`. `job_shipment_statuses` tak pernah ditulis/dibaca (dead code). | **MERGE** (aman data): karena `job_status_history` sudah memuat entri shipment yg tidak bisa dipisah dari entri status job (tanpa diskriminator), pertahankan `job_status_history` sbg satu riwayat; **hapus** tabel `job_shipment_statuses` + model `JobShipmentStatus` (kosong, tanpa data). Alternatif split hanya bila perlu label terpisah → migrasi data dgn watermark, lebih berisiko. |
| Dashboard per-role (CS summary; Operation job aktif) | Dashboard tunggal `/dashboard` | Tidak ada dashboard terpisah; CS (`DashboardService.php:69-79`) & Operation (`:74-79`) = widget berbeda dalam satu dashboard. | Tidak ada tindakan (sudah konsolidasi). |
| Activity Log (`activity_logs`) | Finance log terpisah | Tidak ditemukan sistem log kedua (grep `audit_log`/`finance_log` = 0). Module finance = filter `module` di satu log global (`AccessController.php:51-76`). | Tidak ada tindakan (sudah satu engine). |
| Vendor Shipping Lines / Trucking / Agent Int'l / Agent National | Vendor Master | Sudah SATU tabel `vendors` (`2026_09_09_000003`) + pivot `vendor_categories` (`2026_09_11_000002`); kategori di `config/operations.php:8`. | Tidak ada tindakan (sudah konsolidasi). |
| CS upload dokumen vs Operation upload dokumen | Job Document Center | Sudah satu `JobDocumentController` + tabel `job_documents` shared; bedanya hanya permission (`jobs.view` diberikan utk CS & Operation). | Tidak ada tindakan (sudah konsolidasi). |
| Volume calculator page vs CBM calculator page | Shipment Calculator | Sudah satu halaman `calculators/volume-weight.blade.php` menampilkan Volume Weight & CBM sekaligus (`CalculationService.php:11-30`). | Tidak ada tindakan (sudah konsolidasi). |
| PDF: SK DO / Surat Jalan / Tanda Terima / Quotation / Job Order | Document Generator Engine | Semua via satu engine dompdf (`OperationalDocumentController.php:97-149`, `app('dompdf.wrapper')`), template Blade terpisah. | Tidak ada tindakan (engine reusable). |
| `/reports/profit-bulanan` (`web.php:65`) | `/reports/profit-per-job` | Bukan duplikat (bulanan vs per-job), hanya path campur bahasa Indonesia/Inggris. | Opsional: samakan format path (housekeeping, tanpa ubah fungsi). |

**Catatan integritas data**: seluruh keputusan MERGE/REMOVE di atas tidak menghapus data bisnis (customer/quotation/job/invoice/jurnal); hanya merapikan route dan dead code. Tidak ada drop tabel berisi data.
